## Why load balancing matters

A client that talks to a single app server directly has no path around that
server going down or getting overloaded. A load balancer sits in front of a
pool of servers so the client only ever depends on one stable address.

## What you'll build

You'll route a client through a load balancer to an app server, matching the
same shape this chapter's blueprint checks for.
