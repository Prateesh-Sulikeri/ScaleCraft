Welcome to ScaleCraft. This first chapter is about the tool, not about
architecture: you'll learn the Design Editor by using it on a small design
that's already broken.

## What you'll do

The starter design on the canvas has two real faults in it, put there on
purpose. You'll run Validate, read what it found and why, fix both problems,
and then Submit to complete the chapter. That is the loop every later chapter
runs on, so it's worth doing once slowly.

A guided tour starts automatically when you open the Design Editor and walks
through it with you. It points out each part of the editor and, at a few
steps, waits for you to perform the real action yourself - select a component,
open the component picker, place the missing piece, run Validate.

## Validate and Submit are different

Validate is the quick check you run while you're still building. It looks at
this chapter's rules and always explains what it finds - never just "invalid".

Submit is the completion gate. It runs the same check first, and only if your
design is structurally sound does it compare the design against the approach
this chapter is teaching. A design can be perfectly valid and still not be the
one the chapter is after, so the two buttons answer genuinely different
questions.

## If you get stuck

Every chapter can carry an optional hint, in the sidebar beside the canvas.
Hints never open themselves - you'll only see one if you ask for it, so you
always get the chance to reason your own way out first.

You can pause the tour with Esc and resume where you left off, or skip it and
replay it later from the pill in the corner of the canvas.
